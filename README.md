# SmartDesk Enterprise Management System

## Overview

SmartDesk is an enterprise project and employee management system developed using Laravel. It provides project management, task assignment, employee management, attendance, leave management, AI assistance, analytics, and Kubernetes deployment.

---

## Features

- Authentication
- Employee Management
- Company Management
- Project Management
- Task Management
- Attendance
- Leave Requests
- Timesheets
- AI Productivity Assistant (Gemini API)
- Activity Timeline
- Analytics Dashboard
- REST API
- Docker Support
- Kubernetes Deployment
- Terraform Infrastructure
- PDF & Excel Reports

---

## Tech Stack

Backend
- Laravel 12
- PHP 8.2

Frontend
- Blade
- Bootstrap 5

Database
- MySQL

DevOps
- Docker
- Kubernetes
- Terraform
- GitHub Actions

AI
- Google Gemini API

## Installation

```bash
git clone <repository>

composer install

npm install

php artisan migrate

php artisan serve
```
